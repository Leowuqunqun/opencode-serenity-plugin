# Skill: {{prefix}}-compass — 方向判断

> 方向信号层：对新需求或探索方向产生观察，不评分不推荐不闭合。

## 用途

Compass 是一个**方向信号层**，用于在投入精力之前评估一个方向是否值得推进。它不做"好/坏"的二元判决，而是产生三个通道的信号：

| 通道 | 含义 |
|------|------|
| **决策质量** (D) | 需求定义是否清晰、边界是否划定、关键变量是否已定义 |
| **工程困难** (E) | 实现该方向的技术复杂度和已知风险 |
| **知识价值** (K) | 探索该方向能获得多少可记录、可复用的新知识 |

## 使用方式

当遇到新需求或新方向时，加载本 skill 并按以下步骤：

1. 收集需求信息和上下文
2. 评估三个通道的信号（高/中/低）
3. 输出信号报告（不需要做决定）
4. 决策由人类或会话组织者做出

## 注意

- compass 不消耗 LLM 推理资源做推荐
- compass 的三个通道信号可用于风险规避和优先级讨论
- compass 的结果应当写入 AGENT_SESSIONS 的进度记录中
