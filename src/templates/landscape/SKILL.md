# Skill: {{prefix}}-landscape — 全景地图

> 项目/系统的架构全景、仓库分类、技术栈和关联关系。

## 用途

提供宁静号实例所管理的系统/项目的全景视图，用于：
- 快速定位服务和代码归属
- 理解仓库之间的依赖关系
- 发现常用操作和入口

## 全景地图内容

| 分类 | 说明 |
|------|------|
| **领域层** | 按业务功能域划分的子系统/模块 |
| **技术栈** | 各模块使用的编程语言、框架、中间件 |
| **仓库关系** | 仓库之间的依赖调用关系 |
| **常用操作** | 各模块的启动、构建、测试、部署命令 |

## 维护

全景地图需要定期更新。建议每次新增/变更仓库时同步更新本技能的文件。
